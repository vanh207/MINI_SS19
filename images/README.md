## 🚀 Cách Thêm / Thay Thế Ảnh Sơ Đồ Của Bạn

1. Vẽ sơ đồ của bạn trên các công cụ như:
   - **draw.io** (diagrams.net)
   - **PlantUML**
   - **StarUML** / **Visual Paradigm**
   - Hoặc chụp ảnh màn hình thiết kế Figma.

2. Xuất file với định dạng **PNG** (khuyến nghị độ phân giải 1200x800, 1600x900 hoặc 1920x1080 để hình ảnh sắc nét).

3. Đổi tên file ảnh đúng theo bảng trên (ví dụ: `Activity_Order.png`).

4. Copy / Kéo thả file ảnh của bạn vào thư mục `images/` này (chọn **Ghi đè - Overwrite**).

5. Mở lại hoặc Refresh trang `index.html` trong trình duyệt:
   - Các slide và tài liệu sẽ tự động hiển thị bản vẽ mới nhất của bạn!
